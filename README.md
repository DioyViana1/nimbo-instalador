# Nimbo para computador

Conversa nas nuvens: chat, voz, vídeo e tela com os amigos.

| Computador | Baixar |
| --- | --- |
| Windows 10 e 11 | [Nimbo-Windows.exe](https://github.com/DioyViana1/nimbo-instalador/releases/latest/download/Nimbo-Windows.exe) |
| Mac com chip M | [Nimbo-Mac-M.dmg](https://github.com/DioyViana1/nimbo-instalador/releases/latest/download/Nimbo-Mac-M.dmg) |
| Mac com Intel | [Nimbo-Mac-Intel.dmg](https://github.com/DioyViana1/nimbo-instalador/releases/latest/download/Nimbo-Mac-Intel.dmg) |

Para criar a conta é preciso ter um convite de quem já usa.

**Windows:** se aparecer a tela azul de proteção, clique em *Mais informações* e *Executar assim mesmo*.

**Mac:** arraste para Aplicativos e abra. Depois do aviso, vá em *Ajustes do Sistema*, *Privacidade e Segurança*, *Abrir Mesmo Assim*.
